Rung 1 · Simple

The doctrine's own grayscale ramp, #141414 to #F2F2F2. No gradient, no shadow stack, no texture, no spring, no red. Values cut frame to frame. The task must still complete: read what the trip costs, read which lines are not costed, and send it.

Every state below is DRIVEN, not drawn. The selector changes the data the same render path consumes.

Rung 2 · Pushed

Three studies. Each moves exactly one axis and leaves everything else at the Simple rung, so each claim can be falsified on its own.

Study A — the material axis

Claim: the four finishes of section 2 are distinguishable as materials at working distance with no label, and the ink-plate law is forced by the metal rather than chosen — no ink of any lightness reaches 4.5:1 on brushed aluminium (best stop 2.20:1), while strobe white on the inset black reaches 14.58:1.

vs Simple: Simple has one flat #1f1f1f for every surface, so the band, the plinth and the readout are the same object at three sizes.

Study B — the confirmation axis

Claim: a broken ring reads as "not yet" before any label is read, and the seat is legible as a single event because it is Anchored with zero overshoot. Drag the slider: the offset is a live redraw of the error, never an idle animation.

vs Simple: Simple prints "20/44 costed" and nothing else, which is true and requires reading. The ring is the same fact at a glance, and it is the same fact — it is driven by the same number.

Study C — the readout axis

Claim: position on a track answers "where is the money" in one reading; a filled bar answers "how much of the whole" and cannot be read for a third retailer at all. Section 9 names the failure — "a value that is really a position on a line is drawn as an angle instead" — and this is the same argument one dimension down.

vs Simple: Simple has the three subtotals as three numbers in a column. The track adds the one thing the column cannot give — the distance between them.

Rung 4 · Signature

The one move only this language would make. Section 7: "when every flush-check ring on the screen reads true at once — no pending value, no live error anywhere — every ring aligns in the same frame into one continuous unbroken line running across the whole composition, the horizon completing itself ... and it un-fires the instant any one value drifts again."
